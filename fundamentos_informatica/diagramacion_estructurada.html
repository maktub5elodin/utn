01Las reglas del diagrama

Todo lo que dibuja el profesor vive dentro de un único rectángulo grande, sin flechas ni saltos: se lee de arriba hacia abajo, y solo existen tres formas de estructurar el flujo.

  1. Todo el algoritmo cabe dentro de un rectángulo grande; ese rectángulo es la función completa.
  2. Secuencia: cajas apiladas una debajo de otra, separadas por una línea horizontal.
  3. Selección: la condición va arriba; abajo el bloque se parte en rama V (verdadera) y rama F (falsa).
  4. Iteración: arriba el rango o la condición del bucle (Para / Mientras); abajo, anidado, el cuerpo que se repite.
  5. Cualquier nivel de anidamiento se resuelve dibujando la estructura completa dentro de la celda que le corresponde — nunca se sale del contorno del padre.
  6. Cuando una condición combina varios criterios con "y" lógico, se descompone en varias selecciones anidadas, una por criterio — nunca una sola caja con una condición compuesta.

04El ejemplo modelo — Problema 13

por qué este es el ejercicio a memorizar

El profesor resolvió este problema de punta a punta en el pizarrón — inicialización, cascada de clasificación, y los seis Informar/Si finales — y marcó con círculos numerados (1a, 1b, 1c, 2a, 2b, 3) exactamente qué línea del diagrama contesta cada inciso del enunciado. No hay que adivinar su criterio acá: preparar este ejercicio es reproducir la solución que él mismo mostró como válida.

La estructura general: se inicializan los contadores, se lee un postulante, y mientras no llegue el registro centinela, se clasifica cada uno según su cargo. Solo puede pertenecer a un cargo a la vez, así que la clasificación es una cascada Si/Sino-Si — no selecciones en paralelo.

// inicialización
CONTGI <- 0 ; CONTAI <- 0
CONTGA <- 0 ; CONTAA <- 0
CONTATM <- 0
Leer ApyN
Mientras (ApyN <> "ZZZZ ZZZZZ")
  Leer cargo, sexo, edad, cond
  Si cargo == "IM/100"
    V: CONTGI++
       Si sexo == "M"
         V: Si 25<=edad<=30
              V: Si cond==1
                   V: CONTAI++
                   F: (nada)
              F: (nada)
         F: (nada)
    F: Si cargo == "A/200"
         V: CONTGA++
            Si 25<=edad<=30
              V: CONTAA++
              F: (nada)
         F: Si cargo == "TM/300"
              V: Si 20<=edad<=30
                   V: CONTATM++
                   F: (nada)
              F: Informar "Error de tipeo: el cargo no corresponde a ninguna referencia"
  Leer ApyN
// fuera del Mientras
Informar "Se presentaron:", CONTGI, "postulantes para IM/100, de los cuales", CONTAI, "cumplen las condiciones"
Si CONTAI >= 3

  F: Informar "No se cubren los cargos solicitados de IM/100"
Informar "Se presentaron:", CONTGA, "postulantes para el cargo A/200"

  V: Informar "Se cubren los cargos solicitados de A/200"

06Cómo piensa el profesor

Patrones que se repiten en todas sus resoluciones de pizarrón — vale la pena replicarlos aunque el ejercicio del parcial termine siendo otro.

  • bucleFor cuando el enunciado da un rango fijo (Para hora=0 hasta 23); Mientras con centinela cuando dice "hasta ingresar un registro cuyo valor es X" — que es el caso de casi toda la guía.
  • inicializaciónTodos los acumuladores y contadores en una sola línea, antes del bucle, separados por comas.
  • paralelo vs. cascadaSelecciones independientes en paralelo cuando un mismo registro puede activar más de una actualización a la vez (mínimo y máximo de una misma lectura). Cascada Si/Sino-Si cuando el registro solo puede pertenecer a una categoría de un conjunto cerrado (un cargo, un rubro, un rango de importe).
  • condicionesDescompone cualquier condición con "y" lógico en varias selecciones anidadas, una por criterio simple — nunca una sola caja con una condición compuesta.
  • nombresMinúsculas para variables auxiliares dentro del bucle (num, temp, tmin); mayúsculas para los acumuladores finales que se informan (SUMPOS, TMAX, HMAX).
  • asignaciónUsa <- dentro del cuerpo del algoritmo, no =.
  • salidaTodos los Informar van juntos al final, fuera de cualquier bucle, con texto literal entre comillas intercalado con las variables.
  • bucles anidadosMarca el alcance de cada for anidado con una flecha vertical a la izquierda del diagrama — un refuerzo visual propio, no parte estricta de la notación, pero es lo que reconoce de un vistazo al corregir.

07Plan de estudio

Orden de prioridad para las horas que quedan antes del parcial.

  1. 13

    Memorizar y poder reproducir esta resolución completa

    Es la apuesta más segura de toda la guía: ya no es "aplicar su estilo", es reproducir lo que él mismo dibujó, con los mismos nombres y los mismos umbrales.

  2. 15

    Plan B — lluvias

    Cubre el otro patrón fuerte de la cátedra: agrupamiento + acumuladores + seguimiento de un extremo, visto en el ejemplo de temperatura máxima/mínima.

  3. 16

    As bajo la manga si el tiempo apremia

    Misma cascada Si/Sino-Si que el 13, pero en 4 ramas y sin los niveles anidados de sexo/edad/condición — mucho más rápido de dibujar.

  4. 12

    Práctica adicional

    Misma lógica de cascada de rangos mutuamente excluyentes que el 13, con montos en vez de cargos.

  5. 14

    Dejar para el final

    El único sin evidencia de cómo lo resolvería el profesor — requiere correlacionar dos tipos de registro distintos.
